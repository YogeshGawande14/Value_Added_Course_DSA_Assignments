# 📘 Value Added Course – DSA & Logic Building  
### Instructor: Prathmesh Ghatmal Sir  

This repository contains notes, code examples, and practice problems from the **Value Added Course on Data Structures and Algorithms (DSA) and Logic Building**.  
The goal is to strengthen **problem-solving skills**, improve **logical thinking**, and build a solid foundation in **mathematical programming concepts**.

---

## 🚀 Contents
- **Prime Number**
  - Check if a number is prime (`isPrime`)
  - Count primes in a given range
- **Perfect Number**
  - Check if a number is perfect
  - Generate perfect numbers up to a limit
- **GCD & LCM**
  - Euclidean Algorithm for HCF (GCD)
  - LCM using GCD relation
- **Divisor Problems**
  - Find all divisors of a number
  - Sum of divisors
  - Highest/lowest divisor logic
- **Mathematical Logic Building**
  - Square root calculation
  - Factorial problems
  - Number theory basics (modulo, remainders)
  - Logic puzzles and reasoning exercises

---

## 🛠️ Languages Used
- **Java** (primary language for DSA practice)  
- **Python** (for quick prototyping and logic building)
